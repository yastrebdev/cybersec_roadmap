# REDPATH Roadmap

Интерактивный учебный ресурс по пентестингу и Python.

Роадмап рассчитан на 24 недели при нагрузке 8–10 часов в неделю. Он последовательно охватывает Linux, сети, веб-безопасность, API, эксплуатацию систем, Active Directory, Python-автоматизацию и отчётность.

## Содержимое

```text
redpath-roadmap/
├── index.html       # Главная страница
├── styles.css       # Основные стили
├── script.js        # Логика и данные роадмапа
├── library.html     # Каталог учебных материалов
├── library.css      # Стили библиотеки
├── library.js       # Поиск, фильтры и прогресс чтения
├── lesson.html      # Страница чтения Markdown
├── lesson-reader.js # Безопасное отображение Markdown
├── lessons/         # Подробные уроки и главы учебников
├── README.md
└── .gitignore
```

## Как использовать

1. Открой интерактивный роадмап.
2. Выбери текущую неделю.
3. Прочитай соответствующий урок в `lessons/`.
4. Выполняй практику в отдельном репозитории `redpath-practice`.
5. Переходи дальше после выполнения критериев готовности.

Пример:

```text
lessons/01-laboratoriya-i-linux-cli.md
lessons/02-tcp-ip-dns-i-trafik.md
lessons/03-linux-iznutri.md
```

## Принцип обучения

Каждая неделя строится по схеме:

```text
теория → ручная практика → лаборатория → Python → самопроверка
```

Задача роадмапа — не дать список инструментов, а сформировать понимание:

- как устроена исследуемая система;
- где проходят границы доверия;
- как формулировать и проверять гипотезы;
- как подтверждать уязвимость минимальным воздействием;
- как документировать результат.

## Прогресс

Интерактивная версия сохраняет прогресс в `localStorage` текущего браузера.

Отдельно сохраняются выполненные задачи роадмапа и прочитанные материалы библиотеки.

Перед очисткой данных браузера рекомендуется экспортировать прогресс в JSON.

## Библиотека

Каталог строится из файла `lessons/lessons.json`. Чтобы добавить новую главу:

1. Создай Markdown-файл в `lessons/`.
2. Добавь его описание в `lessons/lessons.json`.
3. Открой сайт через HTTP-сервер или GitHub Pages.

Первый учебник — «Сети с нуля» — состоит из семи последовательных глав: устройство сети, Ethernet и ARP, IPv4 и подсети, маршрутизация, TCP/UDP, DNS/HTTP/TLS и диагностика Linux.

## Связанный репозиторий

Практические работы, журналы, Python-скрипты и учебные отчёты хранятся отдельно:

```text
redpath-practice
```

## Этика

Все проверки должны выполняться только:

- на собственных системах;
- в учебных лабораториях;
- на целях с явным письменным разрешением.

Не используй материалы проекта для несанкционированного доступа, нарушения работы систем или получения чужих данных.
